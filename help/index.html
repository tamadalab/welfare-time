🍽️ Welfare TIME とは

「Welfare TIME」は、京都産業大学内の食堂、コンビニ、ショップ、および日替わりで出店するキッチンカーの営業情報を一目で確認できるサービスです。 毎朝7時頃にデータが更新されるよう設定していますが、タスクの渋滞もあり、日によって更新時間はバラバラです。 9時ごろには更新が完了しているようです。

🏃‍♀️ 使い方 / How to use

1. 今日の情報を確認する 📅

トップページを開くと、自動的に「今日」の営業情報が表示されます。現在時刻に合わせて「営業中」「準備中」「営業終了」が判定されます。 今日の営業予定がない店舗は、一覧に表示されません。

2. 日付を切り替える　🗓️

画面上部の「前日」「翌日」ボタンを押すと、現在表示中の日付の前日、翌日の予定が表示されます。 または日付をクリックするとカレンダーが表示されますので、その中で日付を選択すると、特定の日付の予定を確認できます。 「今日」ボタンを押すといつでも当日に戻れますが、本日の予定を表示中はクリックできません。

3. 詳細情報を確認する 🖇️

各カードをクリック（または詳細ボタンを押す）すると、その店舗の公式Webサイトや詳細ページに移動できます。

💬　ステータス表示について

  • 🟢 営業中: 現在、その店舗が営業していることを表します。
  • 🟡 準備中: その店舗がその日、営業予定ですが、営業開始時間の前であることを表します（未来の日付を表示した場合も準備中になります）。
  • 🔵 営業終了: その店舗がその日、営業していましたが、その日の営業が終了したことを表します（過去の日付を表示した場合も営業終了になります）。

💽 データについて

当サイトのデータは以下のソースから自動的に収集（スクレイピング）しています。

  • 大学公式Webサイト（福利厚生・食堂案内PDF）
  • キッチンカー出店情報（Mellow）

注意: 自動収集のため、急な営業時間の変更や臨時休業が反映されていない場合があります。正確な情報は必ず公式の情報でご確認ください。 情報ボタンを押すことで、情報の取得先へのリンクが表示されます。
