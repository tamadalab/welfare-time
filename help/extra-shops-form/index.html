🧰 臨時店舗の JSON を作る

臨時店舗の掲載を依頼するための JSON を、フォームに入力して作れます。入力の誤りをその場で教えるので、書式を覚えなくても大丈夫です。

入力すると、サイトでどのように表示されるかの例も、下に出ます。依頼のしかたは、臨時店舗を載せたいときをご覧ください。

1. 店舗の情報

店舗を区別する名前です。半角の英小文字・数字・ハイフンだけで書きます。あとで変更を依頼するときは、前回と同じ id を使います。
地図上の建物の名前で書き始めると、その建物と連動します。候補から選べます。

2. 営業する日

直前の日の翌日で、同じ時間の行が加わります。

3. 確認

    マップでの見え方（建物にカーソルを合わせたとき）
